# Control OC Project
Main Github repository of a Control OC project.

Control OC - is light, fast operating system, created for full control, and with that - have a bit of security.

[Official site](https://controloc.vercel.app/) • [Source code](https://github.com/ControlOC/ControlOC-Source-Code/)

## Why Control OC?
## 3 targets of Control OC:
* **Lightweight operating system:** Only **210 MB**. It is around 68 times less than a installer of Windows 11.
* **Loading speed:** Around **8 seconds** (installed on HDD with VirtualBox). That is incredible speed.
* **Pre-installed utilities:** Control OC is having a **bunch** of system utilities, that is weighting less than a single .deb package. Those utilities are providing wide functionality of Control OC.

## You think there is no programs for Control OC?
## You've been wrong, and Control OC is providing 4 types of programms:
* **Ckrnl Utility:** Native Control OC utilities, with that you have more widely functions, than normal packages.
* **TCE Utilities:** Native TinyCoreLinux, more native than any else program to Control OC.
* **AppImage Utilities:** Type of programms that is using to have working program on every single Linux-based distribution.
* **Debian Utilities:** Mostly all developers are developing their apps exclusively for Debian Linux, so this is why Control OC supports Debian apps from the box.

And these all 4 types of programms are supported by Control OC, this is incredible.
